# Data Contract Checker

Welcome to the **Data Contract Checker** documentation! This is an open source Python package that enables you to enforce standards in your data contracts.

Think about enforcing naming conventions for your models, enforcing a minimum amount of examples for fields or enforcing a specific regex pattern for versions.

## Data Contract Standard suppport
We support the following data contract standards:

- **ODCS (Open Data Contract Standard)** - versions 2.2.1 through 3.0.2
- **DCS (Data Contract Specification)** - versions 0.9.0 through 1.2.1
