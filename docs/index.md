# Data Contract Checker

Welcome to the **Data Contract Checker** documentation! This is an open source Python package that enables you to parse data contract standards and configure validation checks for your data contracts.

The contract module provides the core functionality for parsing and working with data contracts. It supports the following data contract formats:

- **DCS (Data Contract Specification)** - versions 0.9.0 through 1.2.1
- **ODCS (Open Data Contract Specification)** - versions 2.2.1 through 3.0.2
